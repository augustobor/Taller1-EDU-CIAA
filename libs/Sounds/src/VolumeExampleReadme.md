# Volume Example for EDU-CIAA

Este proyecto es un ejemplo de cómo controlar el volumen dinámicamente en la EDU-CIAA utilizando las bibliotecas de sonido y temporizadores. El volumen se incrementa automáticamente en un bucle y se reinicia al alcanzar un valor máximo.

---

## Instrucciones de uso

### Copiar el archivo de ejemplo
Copia el archivo `VolumeExample.c` al directorio `examples/c/app/src/` y renómbralo como `app.c`. Esto reemplazará el archivo principal del proyecto.
